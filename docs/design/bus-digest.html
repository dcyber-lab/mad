网页（你的 iPhone 上是英文）

几个决定

不再是你的气泡

mad 送消息时就在这一段上做标记，并带上每条消息的数据：谁、哪个群、第几条、几点、是什么（消息、交接、交接结果、提醒）。三端都照这份数据画，不去猜英文。网页在 #170 已经去掉了按文字猜的做法，这次也不会加回来。

只留谁说了什么

开头那段写给 agent 的说明、「做完用 bus_done 回复」、看板编号、「还有几条没 @ 你的」这些都是给 agent 的，不画。agent 照样收到全文，变的只是你看到的样子。

结果只说一次

建 agent、建团队的结果由确认卡片原地那一行来说，mad 发给 agent 的通知不再画。一次送达里只有这种通知时，这里什么都不出现。

点一下回到原处

点一条消息就打开它所在的群或私信，停在那条上，前后文都在。长按复制原话。展开、收起只在这一处，不跳走。

agent 发出去的也用话写

agent 回群、私信、交接、交回结果，现在是一行 mcp__mad__bus_post 之类的工具名。改成「发到 #ios」「私信 reviewer」「交给 builder」「交回结果」，后面跟它说的第一句。用的还是现有的工具行，只是换字。

考虑过、没选的

完全不画：看不出 agent 为什么突然去做一件事。收成一行「收到 2 条消息」：每次都得点开才知道。画成别人发的气泡：左边本来是 agent 自己，对话会像群聊，分不清谁是谁。
