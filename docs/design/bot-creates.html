在对话里让 bot 建 agent 和团队

你在任何对话或群聊里说「帮我建个团队做 X」，bot 先用「想问你」卡片问清缺的信息，再给你一张确认卡片，写明要建什么。你点「允许」才会建，建好后对话里有一行能直接打开，首页上马上出现。和 Grok bot 一样，卡片只负责确认，要改什么就跟 bot 说一句。下面是 iPhone 的 7 屏和 Mac 上的卡片，内容都是示例。

几个决定

建群不用问

要你确认的标准是「会不会启动新的 agent」：启动就会占进程、花额度。建群本身不启动任何东西、不花钱，agent 交接任务时也常建群，每次都问会很烦。要是建群时顺带拉起新 agent，那一步照样要确认。

只问缺的，一张卡片问完

bot 先自己推断：在哪个项目的对话里就用那个项目，模型按角色给推荐。剩下的放进一张「想问你」卡片，最多三四个问题。群聊里发话时，bot 也可以直接在群里用文字问。

卡片只管确认

和 Grok bot 一样，确认卡片上不放下拉框和输入项。要改就点「改一下…」或者直接跟 bot 说，它会出一张新卡片。这样手机上卡片不会变成一张大表单。

叫 agent，不叫 bot

app 里其他地方都叫 agent（「1 个 agent」「这个 agent 已经不在了」），卡片上也写 agent。你更习惯叫 bot 的话，我把全 app 一起改。

「以后不用问」

先不放在卡片上，以后做成菜单里的一个开关。开着的时候不弹卡片，但对话里照样留下「建好了」那一行，你总能看到建了什么。

顺带要修的

手机原生的提问卡片现在标题写着 AskUserQuestion，选项还是一排排大按钮（网页在 #163 已改成小块）。第 1 屏的样子需要原生也改成「想问你」加小块。
